photonicslab.beamqual.MSquared.measure_quality¶

MSquared.measure_quality(z_start=80, z_end=200, num_measurements=12, x_centroid=0.0, y_centroid=0.0, deg=2, debug=False, z0x=None, z0y=None, w0x=None, w0y=None)[source]¶

Calculates the field, intensity, variance and finally M-Squared of the beam between the given ranges.

The beam can also be astigmatic

Parameters

  • z_start (float) – Propagation start range for measurements.
