photonicslab.fdsolver¶

Finite difference solver for a general, second-order differential equations.

Module uses finite differences to solve second order differential equations, saving the output to hdf5 format for each time step to optimise memory utilization. This module can be easily expanded to higher-order equation with even differing partial differentiation terms.
