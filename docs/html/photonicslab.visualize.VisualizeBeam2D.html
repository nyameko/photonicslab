photonicslab.visualize.VisualizeBeam2D¶

class photonicslab.visualize.VisualizeBeam2D(wavelen=0.0001064, waist=0.01915, p=0, l=0, z=0, phi=0, hdf5filename='hdf5db/storage.hdf5', hdf5grp='nb1', hdf5set_phase='phase')[source]¶

Two-dimensional beam visualisation object.

Uses the BeamProp2D class to the generate original and propagated seed beam profiles.

Parameters

  • p (int, p>=0) – Radial mode index denoting number of radial nodes.

  • l (int) – Azimuthal mode index denoting number of intertwined helices.

  • z (float) – Propagation distance along optical axis [cm].

fseed¶

Incident seed beam profile. Default is a Gaussian.
