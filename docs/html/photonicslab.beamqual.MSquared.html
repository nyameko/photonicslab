photonicslab.beamqual.MSquared¶

class photonicslab.beamqual.MSquared(wavelen=0.0001064, waist=0.01915, flens=0.5, p=0, l=0, z=0, phi=0, hdf5filename='hdf5db/storage.hdf5', hdf5grp='nb11', hdf5set_phase='phase', hdf5subgrp='seed_qual', hdf5subset_intensity='intensity', hdf5subset_field='field')[source]¶

Determine the \(M^2\) beam quality factor from simulated or experimental propagation data.

Parameters

  • wavelen (float) – Wavelength of the incident seed beam [cm].

  • waist (float) – Location along z-direction of seed beam waist [cm].

  • p (int, p>=0) – Radial mode index denoting number of radial nodes.

  • l (int) – Azimuthal mode index denoting number of intertwined helices.

  • z (float) – Propagation distance along optical axis [cm].

  • phi (float) – Vortex phase term [rad].

  • hdf5filename (File) – Filename of the HDF5 database.

  • hdf5grp (Group) – Group name of the HDF5 group object, with the thermo-optic and opto-mechanical physics data.

  • hdf5_phase (Dataset) – HDF5 dataset structure name for phase modulation object

  • hdf5subgrp (Group) – Subgroup name of the HDF5 subgroup object to store beam metrics.

  • hdf5subset_intensity (Dataset) – HDF5 dataset name storing temporal intensity function.

  • hdf5subset_field (Dataset) – HDF5 data structure name storing temporal complex field.
