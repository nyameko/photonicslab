photonicslab.heateqn.HeatEqn2D.add_source_from_image¶

HeatEqn2D.add_source_from_image(savepath='images/Q_image.png', center_x=None, center_y=None, q=None, nt_start=0, nt_end=None, w_rgb=[0.8554, 0.0525, 0.0921])[source]¶

Adds a heat source to the current instance of the heateqn2D object from an image file.

Reads in an arbitrary image file, converts this to greyscale with user adjustable rgb weightings. Background subtraction is done automatically and the weighted center of mass is used to center the image, unless center_x and center_y values are provided in which case the source image in centered on those user values.

Parameters

  • savepath (str) – Image filename savepath.

  • center_x (float) – X co-ordinate of the center of mass of the profile of the heat source [cm].

  • center_y (float) – Y co-ordinate of the center of mass of the profile of the heat source [cm].

  • q (float) – Amplitude of Gaussian heat source. Uses class constructor default Qinit.

  • nt_start (float) – Starting time-step from which to add source.

  • nt_end (float) – Ending time-step after which source no longer contributes to solver.

  • w_rgb (ndarray) – Red, Green and Blue weighting factors for grayscale conversion.
