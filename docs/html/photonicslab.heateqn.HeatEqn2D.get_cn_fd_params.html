photonicslab.heateqn.HeatEqn2D.get_cn_fd_params¶

HeatEqn2D.get_cn_fd_params()[source]¶

Return parameters and coefficients to the implicit finite difference approximation, implemented within a Crank-Nicolson Scheme.

\[T_{i,j}^{n+1} - sx\left(T_{i-1,j}^{n+1} - 2T_{i,j}^{n+1} + T_{i+1,j}^{n+1}\right) - sy\left(T _{i,j-1}^{n+1} - 2T_{i,j}^{n+1} + T_{i,j+1}^{n+1}\right) = T_{i,j}^{n} + sx\left(T_{i-1,j}^{n} - 2T_{i,j}^{n} + T_{i+1,j}^{n}\right) + sy\left(T _{i,j-1}^{n} - 2T_{i,j}^{n} + T_{i,j+1}^{n}\right) + ss\times Q^{n}\]

Where T is the solution to the differential equation \(Q_\text{load} = ss\times Q^{n}\) is the driving source term or heat hermal load, \(s_{x_{i}} = \frac{\Delta t}{2}\frac{\kappa_{x_{i}}}{(\Delta x_{i})^2} \text{ for } i \in [1,2,3]\), and \(s_s = \frac{1}{\rho c_{p}}\), forming linear algebra system \(Ax = b\).
