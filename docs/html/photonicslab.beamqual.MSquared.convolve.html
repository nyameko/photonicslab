photonicslab.beamqual.MSquared.convolve¶

MSquared.convolve(z)[source]¶

Two-dimensional Convolution function.

Parameters

  • e0 (ndarray) – Incident field for convolution.

  • z (float) – Propagation distance along z-direction [m].

Returns

The propagation function and normalized intensity profile.

Return type

[propagation, normalized_I] (list)

propagation¶

Type

ndarray
