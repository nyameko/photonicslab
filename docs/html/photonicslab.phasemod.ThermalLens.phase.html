photonicslab.phasemod.ThermalLens.phase¶

ThermalLens.phase(hdf5table='temperature', hdf5dset_phase='phase', hdf5dset_phase_collapsed='phase_test', wavelen=0.0001064)[source]¶

Generate transient cross-sectional phase profiles.

Opens HDF5 database containing temporal temperature profiles and generates corresponding transient phase profiles. Phase profile dataset is only created if one does not already exist. Otherwise the values are simply overwritten.

Parameters

  • hdf5dset_temperature (str) – /Path/to/ HDF5 subgroup and dataset for temperature profiles.

  • hdf5dset_phase (str) – /Path/to/ HDF5 subgroup and dataset for phase profiles.

  • wavelen (float) – Beam wavelength [cm].
