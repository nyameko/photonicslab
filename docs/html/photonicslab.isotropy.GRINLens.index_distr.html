photonicslab.isotropy.GRINLens.index_distr¶

GRINLens.index_distr(n0=1.82, b=None)[source]¶

Add the index distribution of the GRaded-INdex of refraction lens.

Parameters

  • n0 (float) – Original / natural refractive index with gain.

  • b (float) – Numerical parameter used in calculation of GRaded INdex of refraction lens formulation. Use None for constant index \(n_0\).

indexN¶

Two-dimensional meshgrid array of graded index of refraction, (repeated along axial or z-coordinate).

Type

ndarray
