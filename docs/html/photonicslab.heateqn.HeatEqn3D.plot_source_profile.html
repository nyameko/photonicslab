photonicslab.heateqn.HeatEqn3D.plot_source_profile¶

HeatEqn3D.plot_source_profile(savepath='images/Q_init3d.png', z_ind=-1, time_step=0)[source]¶

Plot the current cross-sectional source profile from the heat load object.

This method calls the parent / ancestor / super method to do the actual plotting of figures, at the desired z-axial point.

Parameters

  • savepath (str) – Filename to save image file to.

  • z (float) – Source attenuation distance along axial direction and within crystal, \(z=0\) is the pump end-face.

  • time_step (int) – Integer placeholder of temporal indices.
