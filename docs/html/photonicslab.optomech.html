photonicslab.optomech¶

Finite difference solver for the two-dimensional opto-mechanical Paraxial Wave Equation equation using the explicit or implicit methods for isotropic media.

This serves as an initialisation class to generate the initial heat source configuration and to define the material properties of the element to be heated.
