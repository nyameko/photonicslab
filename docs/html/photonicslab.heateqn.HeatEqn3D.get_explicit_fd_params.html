photonicslab.heateqn.HeatEqn3D.get_explicit_fd_params¶

HeatEqn3D.get_explicit_fd_params()[source]¶

Return parameters and coefficients to the explicit 3D finite difference approximation.

\[T_{i,j,k}^{n+1} = T_{i,j,k}^{n} + sx\left(T_{i-1,j,k}^{n} - 2T_{i,j,k}^{n} + T_{i+1,j,k}^{n}\right) + sy\left(T_{i,j-1,k}^{n} - 2T_{i,j,k}^{n} + T_{i,j+1,k}^{n}\right) + sz\left(T_{i,j,k-1}^{n} - 2T_{i,j,k}^{n} + T_{i,j,k+1}^{n}\right) + ss\times Q\text{init}(i,j,k)\]
Returns

Finite-difference integration variables.

Return type

(list)

sz¶

Integration coefficient for second-order finite difference approx along z.
