photonicslab.visualize.Visualize3D¶

class photonicslab.visualize.Visualize3D(z=-1, hdf5filename='hdf5db/storage.hdf5', hdf5grp='nb8', hdf5table='temperature3d', hdf5tabledrive='qinit')[source]¶

Three-dimensional slice-by-slice visualisations of heat source and temperature profiles.

The visualisations are based on monitoring the cross-sectional profile evolution across xy planes and along the xz and yz axes.

Parameters

zz (ndarray) – Meshgrid array description along axial z-direction.
