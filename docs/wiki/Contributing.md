# Contributing to PhotonicsLab

Submit an issue with the physical experiment, supported regime, predicted observable, mathematical/experimental reference and minimal reproducible Python example. A good model contribution includes a clear object interface, physical assumptions, SI units, error/validity domain, analytical baseline, independent numerical comparison if feasible, convergence/uncertainty tests and an educational lesson.

Use reviewed branches, run `uv` quality checks, update supported API docs, keep legacy files archived, and mark future solvers as future. Do not introduce hardware control, closed datasets or nonredistributable solver code by accident. Licence remains GPL-3.0-only; inspect compatibility when importing external code.

When asking for support provide Python/version, command, expected versus observed physics, seed/grid, stack trace without private data, and a source revision. See [Developer guide](Developer-guide.md) and [wiki editorial policy](https://github.com/nyameko/photonicslab/blob/main/docs/WIKI_PUBLISHING.md).
