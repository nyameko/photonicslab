* About
Photonics LABoratory: Software for the simulation, analysis, design, interface
and control of optical hardware and photonics components.
* Installation
Where possible to development and simulation ecosystem will strive to be as
[[https://www.python.org/dev/peps/pep-0008/][Pythonic]] as possible. However, we do accommodate MatLab appliances and
interfaces in many instances.

*** Anaconda
Most of the above dependencies can be satisfied by installing the Python 3.6.
version of [[https://conda.io/docs/user-guide/install/download.html][Anaconda 5.0.1]]. However with regards to the Python Bindings for HDF5,
imaging routines from scikit, the testing framework and Pandoc, you'll need to
run the following within your Anaconda environment.
#+BEGIN_SRC sh
$ conda install h5py
$ conda install scikit-image
$ conda install pytest
$ conda install pytest-cov
$ conda install pytest-xdist
$ conda install pytest-benchmark
$ conda install pandoc
$ conda install cupy-cuda91
# $ conda install cudatoolkit
# $ conda install numba
$ conda install scikit-cuda
#+END_SRC

** Use Git to get source-code
Once you've [[https://bitbucket.org/account/signup/][Created your Bitbucket Account]] and added your [[https://confluence.atlassian.com/bitbucketserver/creating-ssh-keys-776639788.html][public ssh-key]] to the
private [[https://bitbucket.org/account/user/nlcnl/ssh-keys/][Bitbucket NLC Novel Lasers]] repository by emailing it to the [[mailto:Nlisa@csir.co.za][admin]], you
can get access to the source by:
#+BEGIN_SRC sh
$ cd your_desired_working_folder
$ git clone git@bitbucket.org:NLisa/photonicslab.git your_desired_checkout_name

# Or without ssh-keys
$ git clone https://bitbucket.org/NLisa/photonicslab.git your_desired_checkout_name
#+END_SRC

#+RESULTS:

To actively contribute to development of the project, [[https://confluence.atlassian.com/bitbucket/forking-a-repository-221449527.html][Create a Fork]] on your
Bitbucket account and use it [[https://git-scm.com/book/en/v2/Git-Basics-Working-with-Remotes][Locally Edit]] your local checkout of the source
code, then [[https://git-scm.com/docs/git-pull][Pull Changes]] from the original Photonicslab repository, and [[https://help.github.com/articles/pushing-to-a-remote/][Push Your
Changes]] back to your remote Bitbucket account:

#+BEGIN_SRC sh
$ cd your_desired_working_folder
$ git remote add <your_desired_fork_name> <url_to_your_bitbucket_fork>
$ git pull origin
$ git push <your_desired_fork_name>
#+END_SRC

Finally from your Bitbucket account web page, you can then [[https://confluence.atlassian.com/bitbucket/create-a-pull-request-774243413.html][Submit Pull Requests]],
see the [[https://confluence.atlassian.com/bitbucket/tutorial-learn-about-pull-requests-in-bitbucket-cloud-774243385.html][Bitbucket Tutorial]] or [[https://www.atlassian.com/git/tutorials/syncing][Atlassian Git Syncing Tutorial]] should you have any
difficulties.
** Jupyter Notebooks
The developer or end-user can learn to use the software through a series of
[[http://ipython.org/notebook.html][Jupyter Notebooks]], which are included with the [[https://bitbucket.org/nlcnl/varoptic/src][src]]. These lessons provide a set of
interactive literate programming tools that are [[https://drivendata.github.io/cookiecutter-data-science/][very effective]] for exploratory data
analysis. The sub-folder =notebooks/reports= contains more polished work that is
/`near-publication-ready'/. Generally speaking these serve as high level
functional, systems or acceptance tests.

+[[./usage.png]]gs

First change directory into the notebooks folder and then start the notebook
server:

#+BEGIN_SRC sh
$ cd notebooks
$ jupyter notebook
#+END_SRC

This will start the interactive Python session in your browser and from there
you can start the Lessons.

** Continuous Integration and Deployment
By providing a remote, virtual environment, continuous integration practices
permit the building, testing and merging of small code changes frequently, as
opposed to merging in a large change only at the end of the development cycle.

Ensure that you've correctly configured your requirements file:
#+BEGIN_SRC perl
numpy
scipy
matplotlib
h5py
pytest
pytest-cov
pytest-xdist
pytest-benchmark
#+END_SRC

For repositories hosted on BitBucket,
#+BEGIN_SRC yaml
#bitbucket-pipelines.yml
image: python:3.6.4
pipelines:
  default:
    - step:
        caches:
          - pip
        script:
          - pip install -r requirements.txt
          - PYTHONPATH=. pytest --cov=photonicslab -vv
#+END_SRC

For repositories hosted on Github, [[https://travis-ci.org/][Travis-CI]] is the tool of choice, ensure the
configuration file is prepared as follows:

#+BEGIN_SRC yaml
# .travis.yml
language: python
python:
  - "3.6"
install:
  - pip install -r requirements.txt

script:
  - PYTHONPATH=. pytest --cov=photonicslab -vv
#+END_SRC
